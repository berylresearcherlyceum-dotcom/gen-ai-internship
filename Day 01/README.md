## 4. Tasks performed

### Task 1: NumPy Basics
Created a 3×3 NumPy array and performed basic statistical operations like mean and standard deviation.  
Also computed the transpose of the array to understand matrix operations.

### Task 2: Pandas Data Handling
Loaded a CSV dataset using Pandas and explored the data.  
Displayed the first five rows, column names, and checked for missing values.

### Task 3: Data Visualization
Used Matplotlib to create line plots, bar plots, and scatter plots.  
This helped in understanding how data can be visually interpreted.

### Task 4: Mini Logic Check
Implemented a normalization function to scale data values between 0 and 1.  
This is useful for preprocessing data before applying machine learning models.

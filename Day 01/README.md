## 5. Challenge faced and solution
While setting up the project, I faced issues with:

  Python virtual environment activation
  Jupyter Notebook not opening in browser
  PATH and PowerShell command errors

Solution:

Ensured "Add Python to PATH" was selected during installation
Used PowerShell instead of CMD for venv activation
Installed Jupyter correctly using pip install jupyter
Verified installations using:
  python --version
  pip list

This helped me to stabilize the environment and allowed smooth execution of notebook
